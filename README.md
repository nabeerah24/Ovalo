# Ovalo — E-commerce Website

Ovalo is a fictional e-commerce website featuring modern tech products and lifestyle accessories, created as a portfolio project.

## About the Project

This project was created to practice and demonstrate front-end web development skills, with a focus on building a modern, responsive, and user-friendly online shopping experience.

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Features

- Responsive design for desktop, tablet, and mobile
- Product categories and filtering
- New arrivals section
- Product cards with prices and ratings
- Add-to-cart functionality
- Shopping cart data stored using Local Storage
- Add-to-cart notification popup
- Responsive navigation
- Modern e-commerce design
